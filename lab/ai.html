What this experiment is

A publicly inspectable prototype with entirely synthetic enterprise records, bounded model requests, source-linked answers and locally simulated human approval.

What it isn't

An enterprise connector, permission-aware production platform, or an independently validated causal decision engine.

The model integration can remain off while the deterministic lab stays fully interactive. Browser-side prompts never include API keys or real customer data.
